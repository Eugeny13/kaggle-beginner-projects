## 🚢 Titanic: Machine Learning from Disaster
**Link competiție:** https://www.kaggle.com/c/titanic  
- Obiectiv: Predicția supraviețuirii pasagerilor pe baza caracteristicilor.  
- Algoritmi: Logistic Regression, Random Forest  
- Pași:
  - Curățarea datelor și tratarea valorilor lipsă  
  - Encoding pentru variabile categorice  
  - Validare încrucișată (StratifiedKFold)  
  - Export `submission.csv` gata de urcat

📁 Fișier: `kaggle_titanic_starter.ipynb`

## 🏠 House Prices — Advanced Regression Techniques
**Link competiție:** https://www.kaggle.com/c/house-prices-advanced-regression-techniques  
- Obiectiv: Predicția prețului caselor folosind variabile numerice și categorice.  
- Algoritmi: ElasticNet, XGBoost (opțional)  
- Pași:
  - Analiză exploratorie (EDA)  
  - Feature engineering și imputări  
  - Cross-validation (KFold, RMSE metric)  
  - Export fișier final `submission.csv`

📁 Fișier: `kaggle_house_prices_starter.ipynb`
